## ✨ 功能特性

### 📝 待办
- 今日 / 长期双类型，点击即编辑，到期提醒
- 一句话交给 Magic AI 建待办
- **每日打卡**：连续 / 累计天数、鼓励文案、每日提醒，卡片可查看已打卡日期
- **倒数日**：剩余天数，可在日历上标红
- 已完成的待办次日 0 点自动清理（未完成的标注「未完成」）

### 📅 日历
- 日程事件管理，按天查看；月视图按事件真实颜色逐点显示
- 日程提醒（提前 10 分钟 ~ 1 天）
- 时间冲突自动顺延对齐（后一个日程排到冲突结束之后）
- **AI 规划**：填需求 / 现有资源 / 截止时间，自动拆解为可执行方案，一键采纳（日程 + 提醒 + 待办）
- **专注模式**：全屏横屏大字时钟 + 距开始 / 进行中倒计时，屏幕常亮
- 上滑日程列表自动折叠为单周视图

### 📖 日记
- 同一天可记多篇，按时间线合并展示；支持心情标记与本地图片
- 缩略图点击全屏查看：双击放大、双指缩放、拖拽、左右切图
- **日记锁**：数字密码（随机盐 + SHA-256，不存明文）或 指纹 / 人脸 / 设备锁；关闭锁也需验证身份
- **日记自动回复**：写完日记由 Magic AI 以当前人格口吻回复并推送通知
- **AI 笔记**：一句话把聊天记录整理成笔记 → 弹窗预览 → 可提要求重新生成 → 满意后保存到日记（标题前缀「AI笔记：」）

### 🤖 Magic AI
- 对话助手（DeepSeek / OpenAI 及各类兼容端点），历史持久化并标注时间
- 一句话创建 / 修改 / 删除 待办、日程、倒数日、打卡
- 自动注入生活上下文（待办 / 日程 / 日记 / 屏幕时间）做分析与建议
- **Markdown 自动渲染**（设置可开关）
- **聊天记录导出**：可选范围（全选 / 最近 20 条 / 任意勾选）+ 格式（Markdown / `.mgxd` 可导入版）
- **API Key 隐私保护**：密码模式显示 + 小眼睛切换明文
- **获取模型列表**：一键拉取站点可用模型，点选即填

### ⏱ 屏幕时间
- 基于系统 UsageStats 统计使用时长，分类环形图展示
- 日（22:00）/ 周（周日 8:00）AI 报告
- 娱乐超时自动 AI 提醒
- 节能策略：息屏不检查、亮屏 5 分钟一次、无待办不检查

### 💾 数据、同步与隐私
- **`.mgxd` 专属备份格式**（JSON + Base64 图片内嵌，magic=MGXD / version=1.0）
- 选择性导出、导入自动合并（冲突策略：保留两份 / 覆盖 / **跳过重复**）
- 判重规则：**同一类型 + 同一天同一分钟 = 重复项**
- CSV 通用导出
- **局域网同步**：内置 HTTP 服务（ServerSocket，端口 8898），另一台设备浏览器预览 / 下载 `.mgxd`，也能直接下载 App 安装包
- **检查更新**：从 GitHub Releases 获取版本并一键下载安装
- 所有数据仅存本机，不上传

### 🧩 桌面小组件 & 文件关联
- 三个 RemoteViews 小组件：**今日待办**（可直接打勾）/ **倒数日** / **一句话记录**（AI 判断存待办或日记）
- **`.mgxd` 文件关联**：文件管理器 / 浏览器下载里点开即可导入

### 🎨 外观与其他
- 暗色模式（跟随系统 / 浅色 / 深色）
- 功能模块开关（待办 / 日历 / 日记可独立关闭，导航与首页同步隐藏）
- 纯净模式（一键关闭后台保活与全部提醒）

## 📥 下载安装

1. 打开 [**Releases**](https://github.com/MGXD-cheng/magic-note-android/releases/latest)，下载最新的 `MagicNote-<版本号>-release.apk`
2. 手机点击安装；若提示「不允许安装未知应用」，在弹窗里允许即可
3. 浏览器提示「可能有害」→ 选「仍然下载」（自签名 APK 的正常提示）

## 🛠 技术栈

| 层面 | 选型 |
|---|---|
| UI | Jetpack Compose + Material 3，100% Kotlin |
| 存储 | Room（todos / diaries / events / chat_messages / habits / countdowns）、DataStore 偏好 |
| 导航 | Navigation Compose |
| 网络 | OkHttp + OpenAI 兼容 API（DeepSeek 等），XML/JSON 结构化提示词，前缀缓存友好 |

| 依赖 | 零第三方 UI 库（环形图、局域网服务、小组件均自实现） |

## 🗓 更新日志

> 最新在上。每条列出该版本的主要改动。

### v8.2
- **待办小组件按尺寸自适应（空间利用率）**：原来固定显示 3 条、行高固定 26dp —— 拉大了底下大片留白，缩小时又挤。现在读取组件实际高度，**动态决定显示 1~7 条**，行由 `addView` 动态填充、每行 `weight=1` 均分剩余空间 → 高就多显示几条、每行还更舒展；字号 13sp→14sp、勾选圈 20dp→22dp。拉伸/缩小后立即重排（`onAppWidgetOptionsChanged`），不用等 30 分钟周期刷新
- **修复「切深浅色时顶部延迟刷新」（这次的真正根因是三个）**：
  1. 主题值来自 DataStore 的异步 Flow —— 点一下要等 IO 落盘回调才重组。新增 `ThemeModeBus` 进程内即时值，点下即切，DataStore 随后覆盖
  2. `dynamicDarkColorScheme()` 每次重组都重新读几十个系统颜色资源 —— 已用 `remember` 缓存色板，切换那一帧不再变慢
  3. 华为/EMUI 等 ROM 在「透明状态栏」下有自己的一层绘制缓存 —— 现在在主题变化时**显式设置 `window.statusBarColor` / `navigationBarColor`**（Android 15 起该属性失效，自动跳过），状态栏底色随主题立即重绘
- 同时保留 v8.1 的改动：状态栏图标深浅与窗口底色在**组合阶段**同步（不再用 `DisposableEffect` 晚一帧）

### v8.1
- **「闹钟和提醒」授权入口合并进设置页「专注与免打扰」卡片**：一张卡片里同时管「通知访问权限（专注勿扰）」和「闹钟和提醒（准点提醒）」，两行状态灯实时反映授权情况，一键跳转系统设置；从系统设置返回会自动刷新。原「每日汇总」里重复的权限提示已移除
- **新增「✨ AI 改写」入口（编辑日记 / 保存后的 AI 笔记都能继续提要求）**：以前笔记一保存，就再也找不到「提要求让它重写」的入口了。现在打开任意一篇日记 → 正文下方「✨ AI 改写」→ 输入「更简洁 / 分段列点 / 语气活泼些 / 只保留待办」→ AI 改写后直接替换正文预览，不满意可以再提一次，满意再点保存
- **Magic AI 现在知道每条消息是什么时候发的**：聊天历史会以 `[MM-dd HH:mm]` 前缀注入模型（跨年消息带年份），system prompt 里也明确说明该前缀的含义 —— 问「刚才/今天/昨天说了什么」不会再答错，整理笔记时也能写清日期；整理笔记的素材同样带时间
- **修复深/浅色主题切换时「顶部状态栏慢半拍」**：原来状态栏图标与窗口底色是在 `DisposableEffect` 里设置的（组合提交后才执行，天然晚一帧）。现在改为在组合阶段同步应用，并让系统栏样式跟随 App 内主题（而不是系统 uiMode），同时把窗口底色也设为当前主题的 surface 色

### v8.0
- **修复崩溃（重点）**：无「闹钟和提醒」权限时，调度提醒会退回到 `setAlarmClock()`，而它在 Android 12+ 同样需要精确闹钟权限，于是直接抛 `SecurityException` 闪退。现改为「有权限用精确闹钟，无权限用无需权限的 `setAndAllowWhileIdle`」，并给所有调度加了兜底，任何情况下都不会因为提醒功能崩溃（提醒最多晚一点）
- **崩溃日志统一存到 `Download/MagicNote-crash/`**：以前放在应用私有目录不好找，现在闪退后手机「下载」里会多一个 `MagicNote-crash` 文件夹，里面的 `crash-日期时间.txt` 直接发给开发者即可定位问题。Android 10+ 无需任何权限
- 无其它功能变化

### v7.9
- **修复「检查更新」一直失效（重点）**：更新数据源里的仓库名写的是旧名，导致检查更新永远拿不到结果。已改为当前仓库 `MGXD-cheng/magic-note-android`，现在能正常检测新版本并直接下载安装
- **新增「勿扰」授权入口**：设置页多了一张「专注与免打扰」卡片，实时显示是否已获得「通知访问权限」，一键跳转系统设置授权；进入专注模式时若未授权，会弹出「去授权 / 以后再说」引导（不再是只能看一眼的提示）
- **修复日期选择器「总是选中昨天」**：Material3 DatePicker 的时间戳以 UTC 零点表示「某一天」，之前用本地时区换算，整体差了一天（「今天」按钮也会偏到昨天）。已改为正确的 UTC 换算
- 本版同时包含 v7.8 的全部改动（专注模式自动勿扰、同步统计文案、日程冲突对齐、稳定性专项）

### v7.8
- **专注模式自动开启系统勿扰**：进入全屏专注时自动打开系统「勿扰」，退出后恢复原状态（进入前本来就在勿扰则保持不动）；首次使用会引导授予「通知访问权限」，未授权也不影响专注功能
- **同步结果提示更准确**：不再只报「新增 N 项」——采用覆盖 / 保留两份策略时不会再误显示「新增 0 项」，改为完整列出「新增 X · 覆盖 Y · 保留两份 Z · 跳过 W」，并会提示图片写入失败数量
- **日程冲突规则完善**：新日程与已有日程重叠时，统一让「开始时间更早的那个」的结束时间对齐到下一个日程的开始时间（既包括更早日程被压缩，也包括新日程吞掉后续日程开头时自身收窄），只有仍然冲突时才顺延
- **日期选择新增「今天」快捷键**：一键回到今天；新建时间默认就是今天
- **稳定性专项**：清理全部 `!!` 强制解包（备份导出 / 更新检查 / AI 解析结果 / 进度显示 / 快捷记录提示 / 首页截止提醒等），Markdown 渲染与日记图片回退更稳

### v7.7
- **修复「首次安装后一点开就闪退」（重点）**：保活前台服务原本在 `Activity.onCreate` 阶段就启动 —— 而 Android 12+ 限制「后台启动前台服务」、Android 14/15 校验更严，首次安装后从桌面/安装器冷启时系统可能判定为后台状态，直接抛 `ForegroundServiceStartNotAllowedException`，异常发生在主线程 → 整个进程崩溃。三层加固：
  - **启动时机后移**：改到界面可见（`onResume`）之后再启动，只启动一次；
  - **`KeepAliveService.start()` 全程兜底**：被系统拦截时只记日志、功能降级，绝不让 App 崩溃；
  - **`startForeground` 换用带 `specialUse` 类型的三参数重载**（与 manifest 声明对齐），失败时安静 `stopSelf()` 退出。
- **保活功能定位说明**：它只是「屏幕时间娱乐超时提醒 + Magic AI 待办催促」的增强能力；起不来时这两项自动降级，记账/待办/日历/日记/AI 聊天等核心功能完全不受影响。
- 附带：修复后仍会保留崩溃自诊断（`Android/data/com.magicnote.mgxd/files/crash-last.txt`），方便后续定位。

### v7.6
- **修复 .mgxd 数据链路 5 个隐患**：① CSV 导出行列数不齐导致 Excel 串列（现统一 13 列）；② 外部写成的无符号颜色值会让日程全部退回默认紫（数字段改用 Long 解析再收窄）；③ 导入不再沿用备份文件里的 id（避免 REPLACE 覆盖本地同 id 记录）；④ 判重键从「类型 + 分钟」升级为「类型 + 分钟 + 内容」，同一分钟创建的多条不同记录不再被吃掉；⑤ 图片落盘失败会真实统计并提示（此前恒为 0）
- **局域网同步的聊天记录同步不全（再修）**：聊天判重精确到毫秒（此前只到分钟），同一分钟内多条消息也能完整同步过去
- **Magic AI 删除改为「选择范围」**：聊天页删除按钮不再一键清空，先弹出条目列表勾选（可全选）再删除
- **AI 读取日记更完整**：指定日期时注入**该日期全部日记全文**；未指定时最近 20 篇、单篇上限提到 20000 字
- **日程顺延逻辑改为「前一个压缩」**：新日程与更早日程重叠时，把**更早日程的结束时间对齐到新日程的开始时间**（开始早的结束 = 下一个的开始），只有仍冲突时才顺延新日程
- **UI 自适应与遮挡修复**：日记/待办/日程对话框内容支持滚动（文字放大或备注很长时，底部按钮不再被挤出屏幕）；日记编辑里的图片改为横向滚动，图片再多也能显示和删除
- **暗色模式修复**：首页与「一句话记录」不再按系统深浅取色，而是跟随 App 自身主题（系统亮色 + App 强制暗色时配色不再错乱）

### v7.5
- **局域网同步可选择要同步的内容**：开启前用筛选片勾选「待办 / 日程 / 日记 / 打卡 / 倒数日 / 聊天记录」（支持全选 / 全不选），只把你选的部分打包；运行中改动也即时生效
- **修复「局域网同步时 AI 回复没同步过来」（根因）**：聊天记录的判重键原本只看「同一天同一分钟」，而用户提问与 AI 回复几乎总在同一分钟内 → 第一条导入后，AI 回复被当成重复项直接跳过。现在聊天判重改为 **角色 + 内容 + 分钟**，对话能完整同步
- **Magic AI 可以删除指定消息**：长按任意气泡进入多选模式（也可点选多条），底部出现「删除」，确认后只删掉选中的那几条
- **「整理成笔记」改为按钮**：聊天页右上角 ✨ 按钮 → 弹出列表**勾选要整理的条目**（最近 20 条 / 全选 / 清空）→ AI 只根据这些内容生成笔记；预览弹窗里可以**继续提要求让它重新整理**（沿用同一批聊天），满意再保存到日记
- **动画全面补强**：页面切换改为左右横滑 + 淡入淡出（按 tab 方向）；聊天列表增删消息带位移动画；「思考中」气泡淡入展开 / 退出时卸载
- **桌面小组件优化**：点标题 / 待办文字 → 直接打开对应页面（待办组件跳待办页、倒数日组件跳待办页），圆圈仍然是一键完成；倒数日按紧急度配色（已过/今天=红、7 天内=橙、更远=紫）；空状态与计数文案更清楚

### v7.4
- **Magic AI 聊天记录导出升级**：聊天页导出弹窗可选**范围**（全选 / 最近 20 条 / 任意勾选单条）+ **格式**（Markdown 阅读版 / `.mgxd` 可导入版，后者能在「设置 → 数据备份与迁移 → 导入备份」里把聊天记录导回来）
- **`.mgxd` 新增 chat 类型**：备份导出与局域网导出都会包含 Magic AI 聊天记录（判重同样按「同一类型 + 同一天同一分钟」），导出选择列表里也能勾选聊天

## ⚙️ 环境备注

- SDK 位于 `/root/Android`；ARM64 环境已内置 aapt2 替换（`setup_android_env.sh`）。
- proot 环境 release 打包需合并 `linked-resources-binary-format` 的 `.ap_` 中间产物再签名。
- 本机 `zipalign` 为 x86-64 二进制无法在 arm64 执行，已通过 `packaging { jniLibs { useLegacyPackaging = true } }` 规避（安装时解压 `.so`，不依赖页对齐）。
